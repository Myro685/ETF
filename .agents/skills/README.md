# Projektové skills

Složka je připravená pro skills, které přidáme podle potřeb projektu. Zatím neobsahuje žádný vlastní skill.

Každý skill bude v .agents/skills/<nazev>/SKILL.md s YAML metadaty name a description, jasným rozsahem použití a konkrétním postupem. Skripty a reference přidáme podle potřeby. Obecná pravidla jsou v AGENTS.md a .agents/rules/project.md.
